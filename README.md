<h2 align="center">백엔드와 인프라를 함께 다루는 개발자입니다</h2>
<p align="center">동작 원리를 이해하는 것을 중요하게 생각하고, 배운 내용을 꾸준히 기록하며 성장하고 있습니다.</p>

<br>

### About

- 백엔드(Java / Spring)를 주력으로 하며, 네트워크와 인프라 지식도 함께 갖추고 있습니다.
- 리눅스 서버를 직접 운영하고, 발전소 현장에 출장을 나가 하드웨어 / 소프트웨어를 점검합니다.
- 데이터 흐름과 서버 동작 원리에 관심이 많고, 배운 개념은 그냥 넘어가지 않고 정리해 둡니다.

### 하는 일 / 경험

- Spring(레거시) 기반 웹 서비스 개발 및 운영
- 리눅스 서버 운영 및 관리
- 발전소 현장 출장 점검 (하드웨어 / 소프트웨어)
- Jenkins를 활용한 빌드 / 배포
- WebSocket, SSE 기반 실시간 통신 구현
- Kafka 메시지 처리 구현 경험 (실서비스 적용은 준비 중)
